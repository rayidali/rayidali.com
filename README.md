# rayidali.com

Personal site of [Rayid Ali](https://www.rayidali.com), AI engineer in New York.

![rayidali.com](docs/screenshot.jpg)

A desktop you can poke at: boot screen, draggable windows, a typing terminal, a word search, and a wireframe New York behind it all. Built with Next.js and three.js, deployed on Vercel.

It is also home base for [Cinechrony](https://apps.apple.com/us/app/cinechrony/id6792422740), my iPhone app: [rayidali.com/app](https://www.rayidali.com/app) goes straight to the App Store.
